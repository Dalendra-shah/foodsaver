# FoodSaver 🍲

**Reduce Waste, Feed Lives.**

A Flutter-based mobile app that connects food donors (restaurants, individuals) with people in need — reducing food waste and helping communities.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **UI:** Material 3
- **Fonts:** Google Fonts (Poppins)

## ✨ Features

- User authentication (Login / Register)
- Browse and receive available food
- Donate surplus food
- Real-time notifications
- User profile with donation history
- Admin dashboard: manage users, donations, and reports
- Reward points system
